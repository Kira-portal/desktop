## 🇬🇧 English

### Download

#### Windows

Click to download the latest version:

> ### ⬇️ [Download KiraPortalSetup.exe](https://github.com/Kira-portal/desktop/releases/download/v1.0.0/Kira.Portal-1.0.0.Setup.exe)

Alternatively, you can see all versions on the [**Releases**](https://github.com/Kira-portal/desktop/releases) page.

### Installation

1. Download the **`KiraPortalSetup.exe`** file from the link above.
2. **Double-click** the downloaded file.
3. The installation completes automatically and the app opens.

> **Note:** Because the app is not yet signed with a code signing certificate,
> Windows may show a **SmartScreen** warning on first install. This is normal.
>
> On the warning screen:
> Click **More info** → **Run anyway**.

### Updating

When a new version is released, simply download and run the latest
`KiraPortalSetup.exe` again. Your existing installation updates automatically.

### System Requirements

| Requirement | Value |
| --- | --- |
| Operating system | Windows 10 / 11 (64-bit) |
| Internet | Required (the app connects to `sistem.kiraportal.com`) |

## 🇹🇷 Türkçe

### İndir

#### Windows

En son sürümü indirmek için tıklayın:

> ### ⬇️ [KiraPortalSetup.exe indir](https://github.com/Kira-portal/desktop/releases/download/v1.0.0/Kira.Portal-1.0.0.Setup.exe)

Alternatif olarak tüm sürümleri [**Releases**](https://github.com/Kira-portal/desktop/releases) sayfasından görebilirsiniz.

### Kurulum

1. Yukarıdaki bağlantıdan **`KiraPortalSetup.exe`** dosyasını indirin.
2. İndirilen dosyaya **çift tıklayın**.
3. Kurulum otomatik olarak tamamlanır ve uygulama açılır.

> **Not:** Uygulama henüz kod imzası (code signing) sertifikası ile imzalanmadığı için
> Windows ilk kurulumda bir **SmartScreen** uyarısı gösterebilir. Bu normaldir.
>
> Uyarı ekranında:
> **Ek bilgi (More info)** → **Yine de çalıştır (Run anyway)** seçeneğine tıklayın.

### Güncelleme

Yeni bir sürüm çıktığında, en güncel `KiraPortalSetup.exe` dosyasını tekrar indirip
çalıştırmanız yeterlidir. Mevcut kurulum otomatik olarak güncellenir.
